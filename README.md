# MON IPTV

Projet personnel de playlists IPTV à partir de sources gratuites et autorisées.

## Fichiers
- public/mon-iptv.m3u : playlist principale
- public/live.m3u : chaînes en direct
- public/films.m3u : films autorisés
- public/series.m3u : séries autorisées
- public/guide.xml : base XMLTV
- sources/channels.json : registre des chaînes
- sources/vod.json : registre VOD

## Mise à jour
GitHub Actions génère les playlists deux fois par jour.
Les vidéos restent hébergées par leurs diffuseurs d'origine.

Ne jamais ajouter de liens privés, d'identifiants ou de contenus sans autorisation.
Une playlist M3U ne garantit pas à elle seule une bibliothèque VOD avec saisons et épisodes.
